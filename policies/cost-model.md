# 成本模型

本表比较**已经支付的订阅**与**按量 API 的增量现金成本**。它不给模型质量打分，也不把不同窗口的剩余百分比换算成美元。

资料日期：2026-11-09（Asia/Singapore）。调整路由前复核变化项；价格资料超过一天、来源冲突或账户分组不明时重新查证。

## 固定订阅

这些费用在当前计费周期已经支付。少调用不能收回本月费用；订阅路径的 magpie 参考 API 单价也不能再加到每次调用上。

| 渠道 | 数量 | 每份月费 | 月成本 | 依据 |
| --- | ---: | ---: | ---: | --- |
| OpenCode Go 基础套餐 | 2 | $10 | $20 | [OpenCode Go 文档](https://opencode.ai/docs/console/go/) |
| ChatGPT Plus | 1 | $20 | $20 | [ChatGPT / Codex 价格](https://learn.chatgpt.com/docs/pricing) |
| Grok Pro | 1 | $30 | $30 | 用户确认的续费价；首月优惠 $15，不降低长期基线 |
| **合计** | | | **$70** | 不含未核实的税费与汇兑成本 |

OpenCode Go 的额度按模型分别计算：每个模型的五小时额度为其月额度的 20%，周额度为月额度的 50%。因此两份订阅不是两个无限共享的总量，也不能把不同模型的额度相加。

ChatGPT Plus 的本地消息与云任务共享套餐额度，并且可能同时存在周限制。Codex 上多个 GPT 模型共享同一账户窗口。官方说明 GPT-6.1 Sol 在 Codex 或 ChatGPT Work 的订阅用量中没有长上下文附加费；这不表示其他模型或 API 计费也没有附加费。

Grok 多个模型共享同一 Pro 订阅的周窗口。公开页面的套餐名称可能变化，路由比较以用户确认的 $30/月续费价为准。

## 同一请求的现金比较

比较时记录供应商、模型、账户分组、高峰或非高峰、输入、缓存读取、缓存写入、输出和资料日期。

示例请求：100 万未命中输入、100 万缓存读取、10 万输出，无缓存写入。

| 路径 | 计算 | 增量现金 |
| --- | --- | ---: |
| 已支付的 Go、Plus、Pro 路径 | 固定成本已计入 $70/月 | $0，但消耗相应窗口 |
| DeepSeek Flash，高峰 | `1×0.30 + 1×0.006 + 0.1×1.20` | $0.426 |
| DeepSeek Flash，非高峰 | 高峰价格的一半 | $0.213 |
| 鱼鱼 Opus 5.5，按页面标价 | `1×4 + 1×0.20 + 0.1×20` | $6.20 |
| 鱼鱼 Opus 5.5，若确认 0.2 倍率 | `$6.20×0.2` | $1.24 |

订阅路径没有可直接相加的“每次调用美元成本”。比较它们时看窗口消耗、任务适配、缓存连续性与重置时间。

## 使用规则

- 先确认路径满足任务所需的视觉、上下文和工具能力。
- 在合格路径中优先使用免费、赠费和已购买订阅；不同能力档不按价格强行替代。
- 昂贵按量 API 不进入自动故障转移，只有明确指定时使用。
- 不把订阅参考价、赠费、免费请求和未知价格合并成一个总分。
- 当前 `routing.json` 仍包含鱼鱼路径。这是已应用配置与本成本政策的差异，变更前先运行 `route diff`，不能只修改本表就视为路由已改变。
