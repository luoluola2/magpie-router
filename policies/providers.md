# 供应商档案

这些是由用户确认的接入语义，用于形成提案，不是当前配额快照，也不授予修改供应商、账号或密钥的权限。

| Provider | 接入方式 | 路由评估语义 |
| --- | --- | --- |
| `workbuddy` | 未充值的 Free plan，存在限时免费模型和赠送积分 | 优先发现与验证新的免费候选；区分真正免费、消耗赠送积分与无价格信息，不将整站标记等同于每模型免费 |
| `opencode-go` | 两份相同基础订阅，对应两个独立 API 密钥 | 按密钥观察各自窗口、可用模型和失败情况，再评估路由；两个密钥不是无限的同一池，也不能由单次余额判断优先级 |
| `codex` | ChatGPT Plus 订阅 | 订阅窗口资源；结合其模型能力、窗口节奏及实际任务表现评估，不当作按量付费 API |
| `grok` | Grok Pro 订阅 | 订阅窗口资源；长上下文等能力必须与实时暴露状态一起验证，不据套餐名称推断服务保证 |
| `app-yylx-io-10275`（鱼鱼连线-A\，鱼鱼快跑） | Claude 按量 API 中转 | 价格、缓存和未确认的账户倍率见 `cost-model.md`；仅明确指定时使用 |
| `deepseek` | DeepSeek 官方按量 API | 按 `cost-model.md` 的高峰、非高峰和缓存价格计算；仅明确指定时使用 |

## 证据规则

- `magpie model price <provider/model>` 的显式零价格可证明该路径当时标价为零；`no price is known` 是未知，不是免费。
- Provider 的 `free=yes` 只影响 magpie 的 Free first / Cheapest 路由。对 WorkBuddy 做逐模型经济性判断时，还需价格、赠送积分和实时窗口证据。
- `magpie provider account-models opencode-go` 可区分两个密钥的可用模型。配额接口或密钥用量证据用于观察各窗口，不能把它们合并成单一账户结论。
- `magpie provider` 的展示可能只列一个掩码密钥，不能据此否定第二个密钥的存在。
- 套餐与接入方式会变化；当用户说明或实时证据与此表冲突时，先报告并更新档案，不自动修改账号或密钥。
