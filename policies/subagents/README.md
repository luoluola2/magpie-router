# 通用子代理

本目录是四个通用角色的人手维护源；magpie 资源库负责分配到 Codex 和 Claude Code，客户端原生配置是同步结果。角色绑定现有任务组，具体模型及兜底由路由策略管理。

主代理决定是否委派，并提供目标、必要上下文、工作范围、约束和验收条件；负责整合结果及最终验证。并行写入任务必须划分不重叠的文件范围。角色不继续委派。

Explorer、Architect 和 Reviewer 默认只读，Implementer 只修改分配范围。这些定义是行为约定；只有部署时确认客户端提供并启用原生权限限制，才能将其视为技术约束。

## 部署与验证

部署前盘点现有角色与子代理模型覆盖，准备新增角色、客户端分配和任何覆盖调整的变更清单，并取得本次明确确认。优先使用 magpie 支持的命令；没有对应命令时使用资源库界面，不直接改写 magpie 私有配置。只撤销本次新增分配和本次更改的设置，不覆盖无关配置。
